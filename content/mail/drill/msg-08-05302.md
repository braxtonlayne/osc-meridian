NETWORK CONTROL, ALPHA-01

Drill {drill}, ordered {ordered}, {date}.

{count} site(s) did not report sealed by twice the class seal time and are carried as NO REPORT:

```
{sites}
```

Under :x[OSC-DIR-0433] para 6, Network Control does not chase a site during the drill. The ordering command is asked to obtain from each site listed:

a. the time the order was received at the site, from the site watch log;
b. the time each seal door showed closed and dogged on the site door board;
c. the reason no report was made.

A site carried as NO REPORT may have sealed. The carry is a statement of what Network Control received, not of the condition of the site.

Replies to the Network Control watch. No reply is needed for a site that has since reported in a later drill.
