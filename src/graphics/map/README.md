# @graphics/map

Continental US base map and facility marker system (asset family 3).

The register is a 2008 GIS thick client with one states layer loaded: flat pale land, thin grey
state lines, pale slate water, a faint 5 degree graticule, small labels, a 1 px neatline. No glow,
no hillshade, no dark mode. Colours come only from `src/design/tokens.css` (see `map.css`).
Class is coded by shape, never by colour alone.

## Exports

| Export | Purpose |
|---|---|
| `UsMap(props)` | The map: base layers, markers, labels, tooltip, selection, keyboard. |
| `projectionFor(width, height)` | `d3.geoAlbersUsa` fitted to the 48 contiguous states and DC for that frame. `projectionFor(w, h)([lon, lat])` gives the pixel UsMap draws at. |
| `MarkerGlyph({ cls, size, state?, title? })` | One class marker as a standalone inline SVG (legends, tables). |
| `MarkerShape({ cls, size, state? })` | The same shape as SVG children centred on the origin, for use inside another SVG. |
| `MapLegend({ classes?, revealDelta?, counts? })` | HTML legend panel; class names and counts read from canon. |
| `ScaleBar`, `NorthArrow` | Map furniture in plain line style (UsMap draws both by default). |
| `CLASS_ORDER`, types `UsMapProps`, `MapContext`, `MarkerState` | |

### UsMap props

| Prop | Default | Notes |
|---|---|---|
| `width`, `height` | required | Pixel size of the frame. The SVG is drawn 1:1 so 1 px lines stay 1 px. |
| `facilities` | `canon.facilities` | Positions come from each record's `lat`/`lon` (computed by canon-merge). A record without them is not drawn. |
| `selected` | `null` | Facility id. Drawn with a 1 px black box and a label plate (designation and codename). |
| `onSelect(id)` | | Click, Enter or Space on a marker. |
| `classes` | all four | Classes to plot. |
| `revealDelta` | `false` | DELTA locations are withheld: no DELTA marker, label, tab stop or tooltip exists unless this is true. Revealed DELTA markers stay hollow and grey. |
| `showLabels` | `'alpha'` | `'none'`, `'alpha'`, or `'all'`. |
| `layers` | all true | `{ states?, grid?, furniture? }`: state lines and postal codes; graticule and its frame labels; scale bar and north arrow. |
| `children` | | SVG drawn over the base map and under the markers. A function child receives `{ width, height, projection, project(lon, lat) }`. |
| `overlay` | | HTML positioned over the frame (for example an inset `MapLegend`). |
| `label`, `class` | | Accessible name of the map; extra class on the wrapper. |

```tsx
import { UsMap, MapLegend } from '@graphics/map';

<UsMap width={1200} height={760} selected={id} onSelect={setId} showLabels="alpha">
  {({ project }) => <path d={routePath(project)} class="my-route" />}
</UsMap>
```

## Marker system

| Class | Shape | Fill |
|---|---|---|
| ALPHA | square, with its designation as a label | `--title-active-bg` |
| BETA | diamond | `--title-inactive-bg` |
| GAMMA | hollow circle | `--surface`, 1.5 px line |
| DELTA | small hollow triangle | `--surface`, grey line; only with `revealDelta` |

States: `normal`, `hover` (1 px grey box), `selected` (1 px black box), `dim` (greyed; legend row
for a class that is not plotted). Hover or keyboard focus shows a tooltip plate with designation,
codename, class and class name, posted staff and capacity, all read from canon.

Keyboard: the markers form one tab stop (roving tabindex). Arrow Right/Down and Left/Up cycle
through the plotted sites in class then designation order and wrap; Home and End jump to the ends;
Enter or Space selects. Each marker is `role="button"` with a full `aria-label` and `aria-pressed`.
Focus is a 1 px dotted box.

Labels: greedy placement. The selected plate is placed first, then ALPHA designations, then (with
`showLabels="all"`) the rest. Each label tries E, W, NE, NW, SE, SW, N, S of its marker. ALPHA
labels keep moving outward (with a leader line) until they clear every other label, so they never
overlap; other labels are dropped if no first-ring position is clear. State postal codes give way
to everything. Widths are exact because designations are set in IBM Plex Mono (0.6 em advance).

## Projection, scale and north

- `d3.geoAlbersUsa` (Albers equal-area conic, standard parallels 29.5 N and 45.5 N) fitted to the
  bundled outline of the 48 states and DC. Alaska and Hawaii are not drawn: all 47 registered
  sites are in the contiguous states, and the composite's empty inset corner carries the furniture.
- The scale bar is measured, not assumed: 100 px across the middle of the frame is inverted to
  lon/lat and the great-circle distance taken (statute miles, radius 3,958.8 mi).
- The north arrow points to true north at its own position. In a conic the meridians converge, so
  at the lower left of the frame it leans about 12 degrees east of straight up. That is correct.

## Geometry

`geo/conus.topo.json` is generated by `geo/build.mjs` from `us-atlas/states-10m.json` (US Census
cartographic boundaries): Alaska, Hawaii and the territories removed, shared arcs simplified with
Douglas-Peucker at 0.025 degrees, 38 islets under 0.09 degrees dropped, re-quantized to 1e4. It is
imported as a module, so it ships inside the JS chunk and nothing is fetched at runtime.

| | raw | gzip |
|---|---|---|
| `us-atlas/states-10m.json` (source, not shipped) | 114,554 B | |
| `geo/conus.topo.json` (shipped) | 35,724 B | 11,608 B |
| module code and CSS, minified, without d3-geo / topojson-client | about 16 kB | about 7.2 kB |
| module with d3-geo and topojson-client tree-shaken in | 80.8 kB | 30.3 kB |

Regenerate: `node src/graphics/map/geo/build.mjs`.

## Rendered check

`node src/graphics/map/check/render.mjs` bundles `check/preview.tsx` with esbuild (real
`tokens.css`, self-hosted Plex faces), renders it in headless Chromium through Playwright, and
writes:

| File | What |
|---|---|
| `check/map-1200x760.png` | All 47 facilities (`revealDelta`), ALPHA labels, inset legend. |
| `check/map-600x380.png` | The same at 600 x 380 (10 degree graticule, smaller markers). |
| `check/map-1200x760-alpha03-selected.png` | ALPHA-03 selected, `showLabels="all"`, DELTA withheld. |
| `check/map-600x380-plain.png` | ALPHA and BETA only, grid and state layers off. |
| `check/map-900x570-hover-alpha03.png` | Tooltip plate on hover. |
| `check/map-900x570-keyboard.png` | Dotted focus box and selection after arrow keys and Enter. |
| `check/glyphs-legend.png` | Every glyph in every state at 12, 17, 24 and 48 px; both legend forms. |
| `check/detail-*.png` | 3x details of the furniture, the north-east and the selected plate. |

The script also prints marker counts per frame, label overlaps (none in any frame), the tooltip
text, and the keyboard sequence. Last run: 47 markers with `revealDelta`, 35 without; 0 overlapping
labels among 5, 17 and 35 labels; one tab stop; arrows cycle and wrap; Enter selects.

Numeric checks: `npx vitest run --config src/graphics/map/check/vitest.config.ts` runs
`map.test.tsx` (8 tests): ALPHA-03 lies south of Lexington KY by its 24 anchor miles and inside
the bundled Kentucky outline; ALPHA-02 is north-west of Denver, ALPHA-04 east of Reno; every canon
facility projects inside the frame at both check sizes and inverts back to its lat/lon; markers are
drawn at `projectionFor` of the canon position; DELTA is absent without `revealDelta`.

## Notes for integrators

- The module imports `@canon` for the default facility list, class names and counts.
- `map.test.tsx` lives here rather than under `tests/unit`, so `npm run test:unit` does not pick
  it up; use the command above.
- Additions beyond the contract's bare signature, all optional: `revealDelta`, `overlay`, `label`,
  `class`, `layers.furniture`, function children, `MarkerShape`, `ScaleBar`, `NorthArrow`.
