# Decisions

Choices made where the spec was silent. Newest at the bottom of each section.

## Build and architecture
- **Repo name / Pages base:** `osc-meridian`; `npm run build:pages` builds with base `/osc-meridian/`. Change `MERIDIAN_BASE` if the GitHub repo is named differently.
- **Canon is generated.** `content/canon/canon.json` is produced by `scripts/canon-merge.ts` from `source.json` (lore facts) + `extended-a.json` + `extended-b.json` (invented canon), so "from source" and "extended" stay physically separate. Hand edits go to the inputs, never to canon.json.
- **Every route is a Markdown document.** App views that are mostly interactive (maps, sims, calculators) still have a Markdown page whose prerendered HTML is the static, no-JS version of the page; the app renders the interactive version over it. This makes the 240-page count real on disk and lets the drift test read every page.
- **Redaction releases.** Hidden text never ships in baseline HTML or the search index; it ships in per-key release files (`T2`, `<COMPARTMENT>`, `<COMPARTMENT>+T2`) fetched only once the session satisfies the key. Tier-1 text is never written to disk at all. Release files are technically public on a static host; that is acceptable for a toy and is the only way to un-redact without a server.
- **Compartments** (codewords chosen by the orchestrator): KESTREL transit engineering, HOLLOW detached/unposted personnel, SEXTANT network geography, TALLOW reserves and reactors, BRIAR assurance contingencies, QUARRY Council and governance, LANTERN ALPHA-03 records and vaults (held from login).
- **Agents don't commit**; the orchestrator commits after reviewing each wave.
- **Certified 847 miles (canon extension, G5):** the Council return lists five whole tram links with witnessed acceptance runs at its first cut-off and was never amended: ALPHA-01→BETA-02 218, BETA-02→GAMMA-03 97, BETA-02→GAMMA-04 156, BETA-10→GAMMA-07 189, ALPHA-05→GAMMA-09 187 = 847. No ALPHA rail segment is certified. Defined in src/graphics/tunnelmap/certified.ts; content must cite these links when explaining the figure.
- **Client canon is sanitised.** `content/canon/canon.json` is the full canon for build scripts and tests. The browser bundle imports `content/canon/canon.client.json` (via the `@canon` alias), generated by canon-merge with every tier-1 and tier-2 restricted value removed (tier-1/2 roster names and emails, restricted ALPHA level names, DELTA location detail, heavy weapons). Redacted text must never be recoverable from the bundle either, not just from the DOM.
- **Graphics unit tests** live beside their modules (`src/**/*.test.ts`); vitest includes them.
- **Dependencies pinned at install time (Nov 2026 latest):** Vite 8, Preact 11, TypeScript 6, Zod 4, Three 0.187, xterm 6.
