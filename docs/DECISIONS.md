# Decisions

Choices made where the spec was silent. Newest at the bottom of each section.

## Content
- **Programme years are calendar years.** The Comptroller ledger reports by programme year (JAN–DEC), not federal fiscal year, so segment commissioning dates fall in the years the record cites; "to date" for 2008 means to 31 MAR 2008. Every ledger page states this.
- **DELTA detail is Tier 1 only.** Nothing about a DELTA site beyond designation, class, the 72-hour basis and (at Tier 2) guard count can ever be released.
- **Tier-2 names in documents.** A document may show the name of a Tier 2 official who signed, sent or is addressed in it, as a released paper would. What is withheld is the directory and role assignment (and every Tier 2 non-name value). The same applies to a Tier 2 official's .mer address in a message header or signature they authored. Neither ships in the JS bundle or client canon. Tier 1 names and addresses never appear anywhere. verify-dist enforces this.
- **Workstation ID** is A03-5-114 everywhere (shell, audit, mail, engine).

## Build and architecture
- **Repo name / Pages base:** `osc-meridian`; `npm run build:pages` builds with base `/osc-meridian/`. Change `MERIDIAN_BASE` if the GitHub repo is named differently.
- **Canon is generated.** `content/canon/canon.json` is produced by `scripts/canon-merge.ts` from `source.json` (lore facts) + `extended-a.json` + `extended-b.json` (invented canon), so "from source" and "extended" stay physically separate. Hand edits go to the inputs, never to canon.json.
- **Every route is a Markdown document.** App views that are mostly interactive (maps, sims, calculators) still have a Markdown page whose prerendered HTML is the static, no-JS version of the page; the app renders the interactive version over it. This makes the 240-page count real on disk and lets the drift test read every page.
- **Redaction releases.** Hidden text never ships in baseline HTML or the search index; it ships in per-key release files (`T2`, `<COMPARTMENT>`, `<COMPARTMENT>+T2`) fetched only once the session satisfies the key. Tier-1 text is never written to disk at all. Release files are **obfuscated, not secret**: each is named by a hash of its key (the file list does not spell out compartments) and its body is XORed with a keystream seeded from a fixed salt and the key, then base64-encoded (`src/core/release-codec.ts`). That keeps withheld text out of plain sight in the network tab, but everything needed to decode it ships with the client, so a determined reader can still recover it. That is acceptable for a toy and is the only way to un-redact without a server. verify-dist fails on any withheld string in clear in a release file.
- **Compartments** (codewords chosen by the orchestrator): KESTREL transit engineering, HOLLOW detached/unposted personnel, SEXTANT network geography, TALLOW reserves and reactors, BRIAR assurance contingencies, QUARRY Council and governance, LANTERN ALPHA-03 records and vaults (held from login).
- **Agents don't commit**; the orchestrator commits after reviewing each wave.
- **Certified 847 miles (canon extension, G5):** the Council return lists five whole tram links with witnessed acceptance runs at its first cut-off and was never amended: ALPHA-01→BETA-02 218, BETA-02→GAMMA-03 97, BETA-02→GAMMA-04 156, BETA-10→GAMMA-07 189, ALPHA-05→GAMMA-09 187 = 847. No ALPHA rail segment is certified. Defined in src/graphics/tunnelmap/certified.ts; content must cite these links when explaining the figure.
- **Client canon is sanitised.** `content/canon/canon.json` is the full canon for build scripts and tests. The browser bundle imports `content/canon/canon.client.json` (via the `@canon` alias), generated by canon-merge with every tier-1 and tier-2 restricted value removed (tier-1/2 roster names and emails, restricted ALPHA level names, DELTA location detail, heavy weapons). Redacted text must never be recoverable from the bundle either, not just from the DOM.
- **Graphics unit tests** live beside their modules (`src/**/*.test.ts`); vitest includes them.
- **Dependencies pinned at install time (Nov 2026 latest):** Vite 8, Preact 11, TypeScript 6, Zod 4, Three 0.187, xterm 6.

## Pass two (docs/SPEC-2.md)
- **Graphics models.** For pass two the owner relaxed SPEC §2.5. Existing graphics modules are reused first. New graphics are drawn by Opus subagents, and Fable is used only where an Opus result fails review. AGENTS-LOG records which model drew each graphic.
- **Switching accounts reloads the page** into the chosen account's namespace, so module-level signals can't leak between accounts. The boot self-test is skipped on a switch.
- **Tier 4 sees a small world.** A base document opens for the Tier 4 account only if it is marked `t4: true` or has a Tier 4 variant. Everything else opens as an in-world refusal. Base HTML is the Tier 3 version, so Tier 4 masking is done by refusal, not redaction.
- **The Tier 2 account and Tier 2 names.** The deputy commander's own name and other Tier 2 canon values are not in the bundle. They ship in an encoded canon release (`CANON-T2`, same codec as document releases) that loads only when the session satisfies T2. Like the document releases, it is obfuscated, not secret.
- **Plant state is global.** Doors, drills, isolation, reactors, hoists and dispatched trains are one physical world, shared by every account and synced across open tabs. Mail, audit trail, desktop and clearance are per account.
- **Reactor panel.** Live mode mirrors telemetry and is display-only unless the account is qualified. The training simulator on the same panel is fully operable for every account. A probationary records analyst running a live reactor would fail the honesty test.
- **The strike planner is a planning toy.** It uses cube-root scaling and a four-class hardening table from canon, and every screen and printout labels it a simplified planning model. It has no real weapon names and no effects data beyond that.
- **Real people and events (owner correction, pass two).** Real history: Bush is president, Obama a 2008 candidate, each shown only doing what the public record says. Real public figures may appear lightly, including as members or implied members of the OSC, but never anyone whose membership would tie them to 9/11. Real private individuals are never members. The 9/11 decision belongs to an unrecorded high table (minutes with no names), with no operational detail. Amusement at conspiracy theorists lives in marginalia and minutes asides. See SPEC-2 §5.
